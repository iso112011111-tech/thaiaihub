# Image assets

ไฟล์ในโฟลเดอร์ `public/` ถูกเสิร์ฟที่ root path โดยตรง
เช่น `public/images/covers/seo.jpg` เข้าถึงได้ที่ `/images/covers/seo.jpg`

## โครงสร้าง

| โฟลเดอร์ | ใช้กับ | ขนาดแนะนำ | อัตราส่วน |
| --- | --- | --- | --- |
| `covers/` | ภาพปกการ์ด prompt (`Prompt.coverUrl`) | 800 x 500 | 16:10 |
| `avatars/` | รูปโปรไฟล์ผู้ใช้ (`Author.avatarUrl`) | 128 x 128 | 1:1 |
| `tools/` | โลโก้เครื่องมือ AI (`AiTool.logoUrl`) | 128 x 128 | 1:1 |
| `brand/` | โลโก้เว็บ, favicon, OG image | 1200 x 630 (OG) | — |

## วิธีใช้

1. วางไฟล์ลงโฟลเดอร์ที่ตรงกับประเภท ตั้งชื่อเป็น kebab-case ภาษาอังกฤษ เช่น `ghibli-portrait.jpg`
2. อ้างอิงด้วย path ที่ขึ้นต้นด้วย `/images/...` ใน `data/`

```ts
// data/prompts.ts
{
  id: "p2",
  title: "วาดภาพสไตล์ Ghibli แบบละเอียด",
  coverUrl: "/images/covers/ghibli-portrait.jpg",
  author: { id: "a2", name: "Noda Art", handle: "nodaart",
            avatarUrl: "/images/avatars/nodaart.jpg" },
}
```

ถ้าไม่ใส่ `coverUrl` การ์ดจะใช้ gradient ที่สร้างจาก id ของ prompt โดยอัตโนมัติ
(`components/prompt/CoverArt.tsx`) และ `avatarUrl` ที่ว่างจะแสดงเป็นตัวอักษรย่อแทน

## ภาพ Hero (`brand/`)

กรอบภาพใน Hero กว้างสุด **543 × 406 CSS px** บนเดสก์ท็อป (คงที่ เพราะ layout ตันที่ 1440px)
และเป็นแถบ **~400 × 168** บนมือถือ จอ Retina ต้องการพิกเซลจริง 2 เท่าของค่านี้

สิ่งที่ต้องระวังคือ `object-cover` ไม่ได้ย่อภาพให้พอดีกรอบ แต่**ขยายภาพจนด้านที่สั้นกว่าเต็มกรอบ
แล้วครอบตัดส่วนเกิน** ยิ่งสัดส่วนภาพต่างจากกรอบมาก ก็ยิ่งถูกขยายมาก และต้องใช้ไฟล์ใหญ่ขึ้นตาม

| รูปแบบภาพ | ขนาดไฟล์ที่ควรทำ | หมายเหตุ |
| --- | --- | --- |
| แบนเนอร์กว้าง 3:1 (แบบ `logo2.png`) | **2600 × 870** | ใช้ไฟล์เดียวได้ทั้งเดสก์ท็อปและมือถือ ไม่ต้องแก้โค้ด |
| ตัดมาพอดีกรอบเดสก์ท็อป 4:3 | **1200 × 900** | คมที่สุด ไฟล์เล็กที่สุด แต่ต้องมีไฟล์มือถือแยก |
| ไฟล์มือถือแยก 2.4:1 | **1200 × 500** | ใช้คู่กับแบบ 4:3 ด้านบน |

สูตรคำนวณเวลาเปลี่ยนขนาดกรอบ: `ความกว้างไฟล์ที่ต้องการ = ความสูงกรอบ x อัตราส่วนภาพ x 2`
เช่นภาพ 3:1 ในกรอบสูง 406 → `406 x 3 x 2 = 2436px`

ค่า `sizes` ใน `Hero.tsx` ต้องเท่ากับ **ความกว้างที่ภาพถูกวาดจริง** (`ความสูงกรอบ x อัตราส่วนภาพ`)
ไม่ใช่ความกว้างของกรอบ ถ้าใส่ตามกรอบ เบราว์เซอร์จะดึงไฟล์เล็กเกินไปและภาพจะเบลอ

## ข้อกำหนด

- **ฟอร์แมต**: ใช้ `.webp` เป็นหลัก (เล็กกว่า jpg ~30%), `.jpg` สำหรับภาพถ่าย, `.png` เฉพาะที่ต้องการพื้นหลังโปร่งใส
- **ขนาดไฟล์**: ไม่เกิน 300 KB ต่อภาพ — `next/image` จะย่อและแปลงฟอร์แมตให้เองตอนเสิร์ฟ
- **ห้ามเว้นวรรคหรือใช้ภาษาไทยในชื่อไฟล์** เพราะต้องผ่าน URL
- ภาพจากภายนอกใช้ URL เต็มได้เลย โดเมนถูกอนุญาตไว้แล้วใน `next.config.ts`
